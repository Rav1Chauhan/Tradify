# Tradify — Solana Wallet Telegram Bot

Tradify is a Telegram bot that lets users interact with Solana wallets directly through Telegram. It is built with Bun, TypeScript, Telegraf, and Solana Web3.js.

The project focuses on simplifying basic Solana wallet operations through an interactive Telegram interface.

> **Status:** Early development. Currently intended for Solana Devnet testing only.

## Features

- **Generate Wallet:** Create a new Solana wallet.
- **View Address:** Display your wallet's public address.
- **Check Balance:** Fetch your SOL balance from the configured Solana cluster.
- **Transaction History:** View your latest 10 transactions.
- **Send SOL:** Transfer SOL through a guided process with recipient validation, amount entry, fee estimation, and transaction confirmation.
- **Send SPL Token:** Token transfer menu (implementation planned).
- **Private Key Protection:** Direct private-key export through Telegram is disabled.

## Getting Started

### Prerequisites

- Bun installed
- A Telegram bot token from [@BotFather](https://t.me/BotFather)
- A Solana RPC endpoint

### 1. Clone the repository

```bash
git clone https://github.com/Rav1Chauhan/Tradify.git
cd Tradify
```

### 2. Install dependencies

```bash
bun install
```

### 3. Configure environment variables

Create a `.env` file in the project root:

```env
BOT_TOKEN=your_telegram_bot_token
SOLANA_RPC_URL=https://api.devnet.solana.com
```

Replace `your_telegram_bot_token` with your actual Telegram bot token.

**Never commit your `.env` file or share your bot token.**

### 4. Run the bot

Development mode:

```bash
bun run dev
```

Production-style startup:

```bash
bun run start
```

Open your Telegram bot and send `/start`.

## Network Configuration

Tradify currently defaults to Solana Devnet:

```env
SOLANA_RPC_URL=https://api.devnet.solana.com
```

You can configure another compatible RPC endpoint through `SOLANA_RPC_URL`.

**Note:** The displayed network label and Solscan transaction links are currently hardcoded to Devnet. Update these before supporting another cluster.

## Security and Limitations

Tradify is an experimental project, not a production-ready wallet.

- **In-memory wallet storage:** Wallet keypairs are stored in process memory. Restarting or redeploying the bot loses access to generated wallets.
- **No encrypted persistence:** Secure database storage has not yet been implemented.
- **No recovery system:** Wallet backup and recovery are not currently available.
- **Devnet only:** Do not store real funds in wallets generated by this version.
- **Telegram security:** Never share private keys or seed phrases through Telegram.
- **Single polling instance:** Run only one active long-polling instance per bot token.

Before production use, Tradify needs encrypted persistent storage, a secure recovery design, transaction-state protection, and thorough security testing.
